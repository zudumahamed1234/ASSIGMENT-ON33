# 1, picture one
This code is used to get date information from different TextBoxes  It takes the day of the week, month, numeric day, and year from the TextBoxes and stores each value in a separate variable  This allows the program to use the entered date information later in the program



#PICTURE 2
This code is used to clear the information entered in the TextBoxes and the output label  When the clear operation is performed, the values inside the Day of Week  Month, Numeric Day, and Year TextBoxes are removed The output label is also cleared. This allows the user to enter new date information without the old information remaining on the form.
